# OmniVoice Studio — 本地语音合成（免安装整合包）

双击 **`启动程序.bat`** 即可运行，打开浏览器访问 <http://127.0.0.1:7865>。
**无需安装 Python、无需联网、无需配置**——解压即用。

---

## 一、这是什么

基于 **k2-fsa/OmniVoice**（小米，Apache-2.0）**官方最新 0.2.1 源码**构建的本地语音合成工具，
支持 **600+ 语种零样本语音克隆**与**语音设计**，全程离线运行。

- 内置便携 Python 3.12 运行时 + 全部依赖（PyTorch cu128、transformers、gradio 等）
- 内置模型权重（OmniVoice 主模型 + SenseVoice Small 转写，合计约 3.4 GB）
- 内置 GPU 加速版 PyTorch（CUDA 12.8），NVIDIA 显卡可直接加速；没有显卡自动回退 CPU

## 二、功能

| 标签页 | 说明 |
|---|---|
| **语音合成** | 从音色库选一个音色 → 输入文本 → 生成 |
| **语音设计** | 不提供参考音频，直接组合 性别/年龄/音调/风格/口音/中文方言 生成音色 |
| **音色库** | 新建音色：上传参考音频 → 在波形上拖选要保留的片段 → 命名并保存（音频与参考文本一起落盘）。已保存的音色可试听、裁剪、重新转写、重命名、删除 |
| **合成记录** | 每次合成的参数与产物。可试听、下载、**重新生成**（把当时用的文本与音色填回对应页）、删除、清空 |

参考音频建议 3–10 秒，界面上会实时提示「偏短 / 合适 / 偏长」。裁剪后保存的是**裁剪后的
音频本身**，不是一份裁剪参数。参考音频越长合成越慢，偏长的音色在列表里会标黄。

播放器是一套波形控件：波形 + 播放头 + 时间戳，点/拖波形任意位置跳转；合成结果那个还能
开「剪辑」，拖选一段后直接下载成 wav。

界面右侧可调：语速、固定时长、推理步数、降噪、CFG 引导强度、参考音频预处理、输出后处理。
合成结果自动保存到本目录 `outputs\`（文件名含时间戳），同时记进 `outputs\history.json`
（最多 300 条，只记参数不存音频副本）。「清空记录」只删记录，wav 文件会保留。

## 三、环境要求

- **系统**：Windows 10 / 11（64 位）
- **磁盘**：解压后约 **13 GB**，请预留足够空间
- **显卡**（可选）：NVIDIA 显卡 + 驱动 **≥ 525**（CUDA 12 系列）。无显卡可跑 CPU，但明显更慢
- **内存**：建议 16 GB 以上

> ⚠️ **4GB 显存（如 GTX 1650）用户请注意**：语音克隆模式显存会吃满，速度较慢属正常。
> 建议：参考音频取 3–5 秒、把「推理步数」从 32 调到 16。

## 四、目录结构

```
OmniVoice-Studio\
├─ 启动程序.bat          ← 双击这个
├─ runtime\              ← 便携 Python 3.12 + 全部依赖（含 cu128 版 PyTorch）
├─ OmniVoice\            ← 官方最新源码（.py 明文，可自由阅读/修改）
├─ app\                  ← 本工具的界面与逻辑（config.py 可调参数）
├─ checkpoints\          ← 模型权重
│   ├─ OmniVoice\
│   └─ sensevoice-small\      ← 参考音频转写（0.24 GB，自带标点）
├─ voices\               ← 你保存的音色
└─ outputs\              ← 合成结果（*.wav）
```

## 五、常见调整

**想换/补模型权重**：把权重目录放进 `checkpoints\`，或在系统里设环境变量
`OMNIVOICE_CHECKPOINTS=D:\你的\checkpoints`。都找不到时会自动从 HuggingFace 下载。

**想改生成参数**：编辑 `app\config.py`，例如
`DEVICE = "cuda"` 强制用显卡、`DTYPE = "float32"` 提升精度（更吃显存）。

**想改模型本身**：直接改 `OmniVoice\omnivoice\` 下的 Python 源码即可，重启生效。

**命令行批量合成**：可用
```
runtime\python.exe OmniVoice\omnivoice\cli\infer.py --help
```
